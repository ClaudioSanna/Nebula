# Blaze Muay Thai – app per smartphone

Versione installabile (PWA) della settimana di allenamenti. Funziona anche offline, dopo la prima apertura.

## Dove si trova
GitHub Pages è già attivo su questo repo e pubblica il branch predefinito. Dopo il merge, l'app è online su:

**https://claudiosanna.github.io/Nebula/app/**

(Se la prima apertura dà "404", aspetta uno-due minuti: Pages sta pubblicando.)

## Mettere l'icona sul telefono (Android, Samsung Galaxy S24 FE)
- **Chrome:** apri il link → menu ⋮ → "Installa app" (o "Aggiungi a schermata Home") → conferma.
- **Samsung Internet:** apri il link → menu ≡ → "Aggiungi pagina a" → "Schermata Home".

L'icona (fiamma Blaze) è in `icons/icon.svg`; i PNG si rigenerano da lì.

## Alternativa senza GitHub Pages
Trascina la cartella `app/` su Netlify Drop (app.netlify.com/drop) e usa il link che ti dà.
